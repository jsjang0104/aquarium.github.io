# Aquarium Implementation Plan

**Architecture:** Separate scene rendering (`js/aquarium.js`), portrait/storage helpers (`js/portraits.js`) and UI orchestration (`js/app.js`). HTML and CSS provide responsive controls and an accessible photo editor. Vendor Three.js for self-contained hosting.
**Tech Stack:** HTML, CSS, JavaScript, Three.js 0.180.0; Python Playwright for browser verification.
**Spec:** `docs/superpowers/specs/2026-09-14-aquarium-design.md`
